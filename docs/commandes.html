Commandes

Préfixe : !!. La plupart des commandes existent aussi en version slash. Liste à compléter au fil de l'ajout des cogs dans commands/<catégorie>/.

fun / messages

CommandeDescription
!!say / /say Envoie un message via le bot. Options combinables : *embed (en embed), *as_me / *am (via webhook, "comme" un utilisateur), *chuchotte (message secret révélable par bouton).
— automatique — Le cog AutoEmoji republie automatiquement (via webhook) les messages contenant des emojis custom non affichables, en les remplaçant par l'emoji réel trouvé sur les serveurs du bot.
