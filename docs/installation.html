Installer le bot

Le bot est écrit en Python (discord.py). Ce tuto couvre une installation classique et une installation sous Termux (Android), qui correspond au script de déploiement fourni.

  1. Prérequis

    Python 3.10 ou supérieur, pip, git, et un token de bot Discord créé sur le portail développeurs Discord.

  2. Cloner le dépôt

    git clone https://github.com/kevinraphael95/<nom-du-repo>.git
cd <nom-du-repo>

  3. Installer les dépendances

    pip install -r requirements.txt

    Sous Termux, installe d'abord Python et git via le gestionnaire de paquets : pkg install python git.

  4. Configurer le token

    Renseigne ton token de bot Discord dans le fichier de configuration du projet (variable d'environnement ou fichier .env selon la version du repo).

    Adapte le nom exact de la variable/du fichier à la structure réelle de ton repo — à préciser ici une fois figé.

  5. Lancer le bot

    ./start.sh

    Le script start.sh ouvre un tunnel Cloudflare (cloudflared) pour exposer le panel d'administration, enregistre l'URL du tunnel en base, puis démarre le bot. Sous Termux, il utilise $PREFIX pour localiser les binaires installés via pkg.

  6. Accéder au panel admin

    Le panel (Flask) tourne en local sur le port 5050 dans un thread séparé. L'URL publique, générée par le tunnel Cloudflare au démarrage, est celle à utiliser pour s'y connecter à distance.
