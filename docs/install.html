Guide d'installation

Comment installer et configurer le bot Kisuke Urahara.

1
Prérequis

Assure-toi d'avoir les outils suivants installés avant de commencer.

Python 3.10+ pip Git Compte Discord Developer
2
Créer l'application sur le Discord Developer Portal

Rends-toi sur le Discord Developer Portal et connecte-toi avec ton compte Discord.

  • • Clique sur New Application en haut à droite.
  • • Donne-lui un nom (ex: Kisuke Urahara) et accepte les conditions.
  • • Va dans l'onglet Bot (menu de gauche).
  • • Clique sur Reset Token et copie le token généré (garde-le secret, c'est ton DISCORD_TOKEN).
💡 Ne partage jamais ce token. Si quelqu'un l'obtient, il pourra contrôler ton bot.
3
Inviter le bot sur ton serveur

Toujours dans le Developer Portal, va dans l'onglet OAuth2 > URL Generator.

  • • Dans Scopes, coche bot et applications.commands.
  • • Dans Bot Permissions, coche Administrator (ou les permissions dont ton bot a besoin).
  • • Copie l'URL générée en bas de page.
  • • Ouvre cette URL dans un nouvel onglet, choisis ton serveur et autorise l'invitation.
💡 Le bot apparaîtra hors ligne tant que tu ne l'auras pas lancé avec python bot.py.
4
Cloner le dépôt

Clone le projet depuis GitHub dans le répertoire de ton choix, puis place-toi dedans.

git clone https://github.com/kevinraphael95/discord_bot_kisuke_urahara.git
cd discord_bot_kisuke_urahara
5
Installer les dépendances

Installe toutes les librairies Python requises listées dans requirements.txt.

pip install -r requirements.txt
6
Configurer les variables d'environnement

Crée un fichier .env à la racine du projet et renseigne les variables suivantes.

🔴 Variables obligatoires (le bot ne démarre pas sans elles) :

DISCORD_TOKENToken secret du bot Discord (obtenu à l'étape 2)
ADMIN_PASSWORDMot de passe pour accéder au panel admin (obligatoire si panel activé)
ADMIN_SECRETClé secrète pour les sessions Flask (obligatoire si panel activé)

🟡 Variables optionnelles (valeurs par défaut si absentes) :

COMMAND_PREFIXPréfixe des commandes texte (défaut : !!)
ENABLE_ADMIN_PANELActiver ou désactiver le panel admin (défaut : False)
ADMIN_PORTPort du panel admin Flask (défaut : 5050)
BACKUP_AUTO_HOURSIntervalle en heures entre chaque backup auto (défaut : 0 = désactivé)
GPT_OSS_API_KEYClé API pour le modèle GPT open-source (optionnel)
💡 Le fichier .env ne doit jamais être commit sur GitHub. Il est déjà listé dans le .gitignore.
7
Lancer le bot

Lance le bot directement avec Python :

python bot.py

Ou via le script de démarrage complet (recommandé), qui initialise aussi le tunnel Cloudflare pour le panel admin :

bash start.sh
